# 安全政策 / Security Policy

> 中文在前，英文在后。Chinese first, English below.

## 中文

### 报告漏洞

如果你发现了安全问题（例如仓库里意外出现了密钥、注入点、或能被滥用的逻辑），**请不要公开提交 Issue**。请使用 GitHub 的私密漏洞报告功能：仓库主页 → Security → Report a vulnerability。维护者会尽快确认。

### 范围

- 本仓库的导出代码与文档在范围内。
- 线上的羊毛空间（Muse Space 运行时）不在本仓库的管辖内，运行时问题请通过空间本身的渠道反馈。

### 请勿做的事

- 不要在 Issue、PR 或讨论区贴出任何密钥、token、密码、证件信息。
- 不要用漏洞去爬取、骚扰或攻击任何数据源站点。本项目只读公开页面与公开接口。

---

## English

### Reporting a vulnerability

If you find a security issue (for example, a credential accidentally committed, an injection point, or logic that could be abused), **do not file a public issue**. Please use GitHub's private vulnerability reporting: repo home → Security → Report a vulnerability. The maintainer will acknowledge it as soon as possible.

### Scope

- The exported code and docs in this repo are in scope.
- The live Yangmao Space (Muse Space runtime) is not governed by this repo; report runtime problems through the space itself.

### Please do not

- Post any secret, token, password, or identity document in issues, PRs, or discussions.
- Use a vulnerability to scrape, harass, or attack any data source. This project only reads public pages and public APIs.
